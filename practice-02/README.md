## 4. Модель данных и функции

Задача представлена объектом со следующими полями:

- `id` — уникальный положительный безопасный целочисленный идентификатор;
- `title` — строковое название задачи длиной от 1 до 100 символов после удаления крайних пробелов;
- `completed` — логическое значение состояния выполнения;
- `priority` — приоритет задачи: `low`, `medium` или `high`.

Функция `createTask()` проверяет корректность `id`, `title` и `priority`. При успешном создании возвращается объект с `ok: true` и созданной задачей. При ошибке возвращается `ok: false` и текст ошибки.

Функции `findTaskById()`, `getPendingTasks()`, `getTaskTitles()` и `getTaskStats()` используются для поиска и получения информации о задачах.

Функции `addTask()`, `setTaskCompleted()`, `renameTask()` и `removeTask()` изменяют состояние списка без изменения исходного массива. При успешной операции возвращается новый массив задач. При ошибке возвращается информация об ошибке, а текущее состояние не заменяется.

Назначение файлов:

- `src/data.js` — исходные данные общего и индивидуального наборов;
- `src/task-service.js` — функции создания, поиска, анализа и изменения задач;
- `src/main.js` — общий сценарий, собственные проверки и индивидуальный сценарий;
- `examples/functions-and-references.js` — эксперименты с функциями, объектами и ссылками;
- `checks.js` — автоматические проверки реализации.

**Почему id не равен индексу:** индекс зависит от положения элемента в массиве и может измениться после добавления или удаления элементов. `id` является постоянным идентификатором конкретной задачи.

**Почему getTaskStats возвращает число, а не строку с процентом:** числовой результат можно использовать в дальнейших вычислениях. Форматирование числа и добавление знака `%` выполняется только при выводе.

**Какие объекты копируются при изменении задачи:** создаётся новый массив, а для изменяемой задачи создаётся новый объект с помощью spread-синтаксиса. Неизменяемые задачи могут сохранить свои исходные ссылки.
